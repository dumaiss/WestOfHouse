# M3.5 evidence

`results.json` preserves parsed counters, timer counts and resource reports.
`evidence.tar.gz` preserves the selected raw MAME captures, baseline snapshots,
final sources/EXEs/maps and test logs. Extract into a separate directory to
review. The original story is referenced by hash and is not included.

The performance report identifies interrupted baseline sessions and the
completed final SDK sessions. Target timing and host wall time are distinct.
`SHA256SUMS` covers the evidence archive and parsed records.
