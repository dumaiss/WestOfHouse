# Cellar and Living Room illustrations

Generated with the built-in `image_gen.imagegen` tool using the existing kitchen
and attic originals as style/material references. `manifest.json` preserves the
exact prompts, selected original PNG hashes, reference-image hashes and tool
output paths. Original PNGs are in `originals/`; prompts are in `prompts/`.

- `room-72-state-1`: Cellar, the existing mapped state. Damp masonry, a narrow
  passage, a low crawlway and the foot of an unclimbable steep metal ramp.
- `room-193-state-unbound`: initial Living Room concept, generated before the
  extraction fix assigned its matching binding **room 193, state 1**. The
  original filename and generation metadata preserve that provenance. Rug conceals the trapdoor;
  empty trophy case, brass lantern, sword, nailed-shut door and kitchen doorway.

Both illustrations are source assets for review. They are not declared runtime
resources and have no new hotspot/action tables. Adding these to the game is a
separate integration step. Living Room now has eight assigned states and Attic
has one; see `tools/room-state-extractor/HOUSE-STATES.md`. No alternate Living
Room illustrations were generated by the extraction update.

Rebuild 256×159 RGB and YJK+YAE previews, IMG files and the comparison sheet:

```sh
python3 tools/scene-images/build_house_interiors.py
```

Outputs are in `assets/review/house-interiors/`. The recorded center crops use
BOX resizing and the existing optimized YAE encoder; no AI generation occurs
during conversion. No earlier illustration or runtime mapping is replaced.
